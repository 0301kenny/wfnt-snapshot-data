# AGENTS.md

This repo stores official public after-market snapshots for TW Stock Radar. It is not a real-time feed, alerting service, or place to invent undocumented APIs.

Rules for agents:

- Endpoint allowlist is only the 21 daily endpoints, 9 current monthly endpoints, the TDCC weekly endpoint, the 2 MOPS monthly and 2 MOPS quarterly backfill endpoints, the TAIFEX monthly Put/Call Ratio, foreign-futures, and VIXTWN backfill endpoints, the 4 TWSE plus 4 TPEX daily backfill-only legacy endpoints, the TWSE industry-name reference endpoint, and the 4 FRED full-history series endpoints declared in `scripts/endpoints.mjs`; backfill-only and reference-only endpoints must not enter the daily pipeline.
- The 9 daily and 5 monthly current-only endpoints added by TICKET-299 are raw-only: daily files use the market anchor date, monthly files use the current Taipei month, and neither group may trigger derived or screener work or affect `latestTradingDate`.
- Every `BACKFILL_ENDPOINTS` entry must declare `cadence` as `daily`, `monthly`, or `quarterly`; daily gap coverage is derived from the entries declared `daily` plus each market's close source.
- CLI numeric flags in backfill and gap scripts must use `scripts/lib/cli.mjs`; a bare flag is invalid and must reach the existing numeric guard as `Number.NaN`.
- Do not add other URLs, undocumented data sources, or FRED series beyond those declared in `SERIES_ENDPOINTS`.
- Keep zero npm dependencies. Use Node 22 built-ins only.
- Raw snapshots under `data/raw/` are authoritative bytes from official responses. Do not reformat, filter, sort, or prettify them.
- TWSE/TPEX ex-right annual snapshots use `data/raw/{twse,tpex}/ex_right/{yyyy}/{yyyy}.json`; a historical year is a checkpoint only when its raw records a query end date of December 31 for that year, while the current Taipei year is refreshed on every snapshot run and remains write-on-change.
- Legacy backfill raw snapshots use `data/raw/twse/{mi_index_hist,t86_hist,mi_margn_hist,bwibbu_hist}/{yyyy}/{date}.json` and `data/raw/tpex/{daily_quotes_hist,insti_hist,margin_hist,pe_hist}/{yyyy}/{date}.json`, and preserve official response bytes unchanged.
- Daily gap coverage is market-local: TWSE unions its four daily legacy namespaces with `twse/stock_day_all`, while TPEX unions `daily_quotes_hist`, `insti_hist`, `margin_hist`, and `pe_hist` with `tpex/mainboard_close`. Do not merge the markets or infer gaps from dataset differences.
- `scripts/detect-gaps.mjs` must not run concurrently with `scripts/backfill.mjs`. Its `.gap-scan-cache.json` may contain only dates for which TWSE `MI_INDEX` returned the explicit official non-trading shape, including the original `stat`; request failures and non-200 responses must never be cached.
- `scripts/backfill.mjs --dates` is a hole-fill mode: it bypasses but never updates `.backfill-progress.json`, continues after per-date failures, and exits non-zero after the final summary if any date failed. Today and future dates are invalid in both gap scanning and explicit hole filling.
- `scripts/history-backfill.mjs` is the unattended raw-only 2006–2021 runner. It processes dates newest-first, writes only `data/raw/**`, quarantine, and `data/history-backfill/progress.json`, and must never read or write `.backfill-progress.json`, derived data, or the manifest. Its `data/history-backfill/.lock` may take over only when the recorded pid is no longer alive, and it must pause during the configured Taipei daily window.
- MOPS monthly revenue backfill snapshots use `data/raw/{twse,tpex}/monthly_revenue_hist/{yyyy}/{yyyy-mm}_{0|1}.html`; each file preserves one official big5 response unchanged, where `_0` is domestic and `_1` is foreign companies.
- MOPS quarterly financial backfill snapshots use `data/raw/{twse,tpex}/quarterly_fin_hist/{yyyy}/{yyyy-Qn}.html`; each file preserves one official UTF-8 `ajax_t163sb04` response unchanged, and `scripts/backfill-quarterly.mjs --from` must start at Q1 so later cumulative quarters can be differenced.
- Quarterly refreshes never overwrite the main `{season}.html`: changed official responses append `{season}.rev-{Taipei YYYY-MM-DD}.html`, while derived reads merge every revision oldest-to-newest and retain companies omitted by newer responses.
- `scripts/quarterly-refresh.mjs` is the weekly quarterly-only runner. It rebuilds quarterly derived output only after writing a new main or revision raw file; it must not enter the daily pipeline.
- TAIFEX Put/Call Ratio backfill snapshots use `data/raw/taifex/pcr/{yyyy}/{yyyy-mm}.csv`; each file preserves one official Big5 response unchanged, and only responses that parse to at least one data row are valid raw.
- TAIFEX foreign-futures backfill snapshots use `data/raw/taifex/foreign_futures/{yyyy}/{yyyy-mm}.csv`; each file preserves one official Big5 response unchanged, and only responses whose first line starts with `日期,` and parse to at least one data row are valid raw.
- TAIFEX VIXTWN backfill snapshots use `data/raw/taifex/vix_monthly/{yyyy}/{yyyy-mm}.txt`; each file preserves one official Big5 tab-separated response unchanged, and only responses whose first line starts with `交易日期` and parse to at least one data row are valid raw.
- The TAIFEX foreign-futures endpoint rejects a query end date that is not a trading day that already has data; an out-of-range end date returns HTTP 200 with a 631-byte `DateTime error` page and zero rows, and "today" on a non-trading day returns byte-identical output to a future date. The current month's end date must therefore come from the last trading date in the same month's PCR raw, never from the month end or from today. When that PCR raw is missing or has no rows for the month, the current month is recorded as a failure and no request is sent for it; historical months still run. The PCR endpoint has no such restriction.
- Current-month raw is re-fetched on every run for TAIFEX PCR and foreign futures (`refreshExistingRawForMonth`), while historical months keep the existing-raw checkpoint; VIXTWN refreshes its whole four-month range. Refreshing every month of the foreign-futures range would re-request roughly 35 months and has previously triggered HTTP 429.
- TDCC raw snapshots are stored as `data/raw/tdcc/{yyyy}/{date}.csv.gz`; gunzip output must equal the official response bytes.
- `data/manifest.json` must remain idempotent. A no-op rerun must produce no byte-level diff.
- `data/**` is generated by the pipeline. Humans and agents must not hand-edit generated data.
- Do not ignore `data/`; GitHub Actions must be able to commit generated snapshots.
- `scripts/probe.mjs` and `.github/workflows/probe.yml` are probe artifacts and should remain unchanged unless a ticket explicitly allows it.
- `data/derived/` is a generated read-optimization layer. Raw snapshots remain authoritative, and derived files must be fully rebuildable from raw with `scripts/build-derived.mjs`.
- Derived symbol outputs must exclude only pure numeric 6-character IDs (`/^\d{6}$/`). Use the same rule for daily symbol series and TDCC series.
- Fundamentals derived outputs use the same pure numeric 6-character ID exclusion rule and combine daily TWSE/TPEX valuation, monthly TWSE/TPEX revenue, and MOPS quarterly general-industry margins; monthly OpenAPI raw takes priority, with MOPS historical raw as fallback.
- Quarterly financial derived parsing covers all recognized MOPS industry tables by header features. General-industry margin bytes stay unchanged; non-general tables may emit net margin only, with `gm` and `om` null, and tables without positive single-quarter revenue emit no margin row.
- `data/derived/quarterly_eps.json` contains all-industry single-quarter EPS, uses the same cumulative-quarter differencing and symbol exclusion rules as fundamentals, prefers TWSE on collisions, and keeps 24 quarters per symbol.
- `scripts/rebuild-quarterly.mjs` rebuilds only fundamentals `quarterly` rows and `quarterly_eps.json` from quarterly raw in ascending season order. It must not delete derived files or change valuation or revenue rows.
- Fundamentals series definitions belong in the single registry in `scripts/lib/derived.mjs`, including columns, default windows, updated-date participation, and metadata precedence.
- Incremental derived updates in `scripts/run.mjs` and full rebuilds must share `scripts/lib/derived.mjs`; do not create a second transformation path.
- Derived serialization must be deterministic and write-on-change only, so no-op reruns produce no byte-level diff.
- TWSE sector index derived data includes only index names ending in `類指數`, prefers same-date OpenAPI raw over `mi_index_hist` table 0, and has no rolling window.
- Industry classification uses each market's latest `company_capital` raw, keeps TWSE on cross-market symbol collisions, and resolves official names only from `data/raw/twse/industry_mi_index/{yyyy}/{date}_{code}.json`.
- `REFERENCE_ENDPOINTS.twse_industry_mi_index` is backfill-only reference data. It must not be added to `ENDPOINTS`, `BACKFILL_ENDPOINTS`, `SERIES_ENDPOINTS`, the daily pipeline, or gap detection.
